# **App Name**: Trendify

## Core Features:

- Content Aggregation: Aggregates trending content from various social media platforms, supporting Instagram, X, YouTube, TikTok, and others.
- Trend Prediction Tool: AI tool to analyze content metadata and social signals, to predict emerging trends using LLM reasoning about how tags relate to each other.
- Boom It! Button: Allows users to upvote or 'boom' content to increase its visibility and contribute to trend rankings.
- Tag-Based Filtering: Enables users to filter content by specific tags (location, activity, food) to find trends that match their interests.
- Submit Trending Content: Allows users to submit links to trending content from various platforms. AI tool will identify the relevant platform automatically.

## Style Guidelines:

- Primary color: Vibrant blue (#4285F4), reflecting trust and dynamism.
- Background color: Light gray (#F5F5F5), providing a clean and modern feel.
- Accent color: Soft green (#34A853), complementing the blue and creating visual interest.
- Headline font: 'Space Grotesk', sans-serif, offering a techy, scientific feel.
- Body font: 'Inter', sans-serif, for clear and readable text.
- Use a consistent set of icons from Font Awesome, employing a unified and modern look.
- Implement subtle animations and transitions to enhance user engagement. Animations will focus on calls to action like 'Boom it' button.
